What my full-stack internship at Thiranex taught me

2026 · Internship experience

This year I joined Thiranex as a Web Full Stack Development intern. I had written small programs before, but I had never built an application where the frontend, the API and the database all had to work together. During the internship I built four full-stack projects.

The first big lesson was CRUD. Creating, viewing, updating and deleting data in MongoDB sounds simple, until a typo in a route means nothing saves and you have to trace the request step by step. Postman became my best friend for testing each endpoint before I touched the frontend.

The second lesson was authentication. Adding JWT login made me think about who is allowed to see what, and why a token should never be trusted blindly. That was the moment my projects started to feel like real software.

I also learned that building an app is only half the job. Thinking about deployment early changed how I organised my code and settings.

Next, I want to write clearer documentation for every project and put each one on GitHub with a proper README.

Learning Java and React Native side by side

2026 · Learning journey

I’m in my second year of Computer Science Engineering at JSPM University, and my days are split between two worlds. In class I’m learning Java and object-oriented programming. On my own I’m learning React Native to build mobile apps.

At first it felt like too much. Java asks me to think carefully about classes, objects and structure. JavaScript lets me move fast and fix things later. But I’ve started to notice that each one improves the other. Java’s discipline makes me plan my JavaScript better, and JavaScript’s speed reminds me to build small things and test them often.

The biggest challenge is time. When assignments, practice and self-study pile up, I make a short list each week and finish the hardest task first. It isn’t perfect, but it keeps me moving.

What I enjoy most is the moment something finally runs. Whether it’s a Java program printing the right output or a screen appearing on my phone, that small win makes the effort worth it.

Next, I’ll turn my Java assignments into small projects on GitHub and build my first React Native app.

Task Manager with secure login

Full-stack web app built during my Thiranex internship

Problem statement
People lose track of daily tasks when they keep them in notes or chats. This app gives each user a private place to manage their own tasks.
Description
A Node.js and Express backend exposes REST APIs for tasks, and MongoDB stores users and tasks. A user signs up and logs in, the server issues a JWT, and every task request checks that token so people only see their own data. The frontend is built with HTML, CSS and JavaScript and talks to these APIs.
Concepts used
Node.js, Express.js, REST APIs, MongoDB CRUD operations, JWT authentication
Features
Sign up and login with JWT. Create, view, update and delete tasks. Each user sees only their own tasks. Endpoints tested with Postman.

Student Record Manager (Java)

Java Programming mini project

Problem statement
Keeping student records on paper or in scattered files makes searching and updating them slow and error-prone.
Description
A console program built with object-oriented Java. A Student class holds the data, and a manager class keeps students in an ArrayList and offers add, search, update, delete and sort. Input is validated and errors are handled with exceptions.
Concepts used
Classes and objects, encapsulation, ArrayList and the Collections framework, exception handling, sorting with Comparator
Features
Add, search, update and delete records. Sort by name or marks. Input validation with clear error messages.

Image and Video Helper (Python)

Personal automation project

Problem statement
Resizing images and converting videos one by one is slow and repetitive.
Description
A Python script reads a folder, uses Pillow to resize and convert images in a batch, and calls ffmpeg to convert video files. Results are saved to a separate output folder so the originals stay safe.
Concepts used
Python scripting, file handling, Pillow, ffmpeg, command-line arguments
Features
Batch image resize. Image format conversion. Video conversion with ffmpeg. Separate output folder.
